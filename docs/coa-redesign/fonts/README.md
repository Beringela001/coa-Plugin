# Preview font provenance

Downloaded September 8, 2026 from the official Google Fonts repository:

- Plus Jakarta Sans variable upright: https://github.com/google/fonts/tree/main/ofl/plusjakartasans (`PlusJakartaSans[wght].ttf`, saved locally as `PlusJakartaSans.ttf`).
- IBM Plex Mono Regular and SemiBold: https://github.com/google/fonts/tree/main/ofl/ibmplexmono.

Original SIL Open Font License files are included alongside these binaries. The approved family names match the website's `pepselect-child/assets/css/foundations.css` tokens. Font files are used only by this local preview. There are no remote font requests at runtime and no production font changes. Browser verification confirmed Plus Jakarta Sans and the used IBM Plex Mono SemiBold face loaded; body and metric computed styles select those families.
